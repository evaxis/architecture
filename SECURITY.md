# Security reporting

Evaxis architecture is in the foundation/design stage, without released product
versions or production services.

Use [private vulnerability reporting](https://github.com/evaxis/architecture/security/advisories/new)
under **Security -> Report a vulnerability**, not a public issue or PR.
If that form is unavailable, contact the owner through
[their GitHub profile](https://github.com/goldjg) to arrange a private channel.

Include the affected document/commit, non-sensitive reproduction and expected
impact. Never publish credentials, customer evidence, tenant details or private
reports. Coordinate disclosure; no SLA or bounty is promised.
See the [shared policy](https://github.com/evaxis/.github/blob/main/SECURITY.md).
