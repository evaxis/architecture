# Architecture and roadmap diagram

The supplied source is
[`evaxis_architecture_roadmap_animated.html`](evaxis_architecture_roadmap_animated.html).
It contains interactive architecture, processing, trust, deployment, commercial
and roadmap views. Select a tab or an architecture node to explore its notes.

## View locally

GitHub's file viewer displays HTML source rather than running the diagram.
Clone or download this repository, then open
`diagrams/evaxis_architecture_roadmap_animated.html` in a browser. Alternatively,
use GitHub's **Download raw file** control and open the downloaded file.
Links to neighbouring Markdown documents require the repository checkout;
they are not bundled in a standalone HTML download.
No build, package installation, local server or hosted deployment is required.
The canonical logo is fetched from the organisation avatar URL, so displaying
it requires network access; the diagram's content and interactions are inline.

## Decision status and authority

**Confirmed:** the HTML source is included in this branch. This does not imply
a published website, implemented platform or accepted product specification.

**Proposed:** architecture flows, deployment combinations, product tiers,
illustrative interfaces and future integration stages. Technology/provider
names, encryption details and commercial examples are options, not selections.
Maester remains an optional proposed integration, never Evaxis's execution or
storage foundation. External pricing and source assertions in the supplied
diagram are unverified historical context, not current product contracts.

**Undecided:** implementation language, build system, storage/database, provider,
identity, cryptographic algorithms, licensing, pricing, entitlements and
third-party integration terms. The diagram does not resolve these decisions.

The [confirmed foundation boundaries](../adr/0001-foundation-boundaries.md),
[roadmap](../roadmap/README.md) and canonical cARL governance remain authoritative.
The next milestone is the Evidence Envelope specification and approved
synthetic conformance fixtures, not a Pack implementation or cloud deployment.
Accept future decisions only through reviewed records and reconciled memory.
